# JynxPrime

A Warframe companion app for Windows.

## Download

**[Download JynxPrime (latest version)](https://github.com/Muaphdaan/JynxPrime/releases/latest/download/JynxPrime-share.zip)**

Older versions are on the [Releases](https://github.com/Muaphdaan/JynxPrime/releases) page.

## Install

1. Extract the whole zip to a folder (e.g. `Documents\JynxPrime`). Don't run it from inside the zip.
2. Open the `JynxPrime` folder and double-click `JynxPrime.exe`.
   If Windows SmartScreen warns about an unknown app, click **More info** → **Run anyway**.
3. The first start downloads about 25 MB of game data, so give it a minute.
4. The app starts with a demo account. Connect your own Warframe in **Settings → Account**.

Needs Windows 10 or 11 (64-bit) and the Microsoft Edge WebView2 Runtime. Windows 11 and most Windows 10 PCs already
have it; if yours doesn't, the app says so and opens the download page.

## Updates

The app downloads new versions by itself and installs them when you close it, so keep it in a folder you can write
to (not Program Files). Your data is kept in `%APPDATA%\JynxPrime` on your own PC.

## In-game overlays

Run Warframe in Borderless or Windowed mode, in English. If your menus use Legacy or Custom Menu Scale, set it in
**Settings → In-game overlays** (or pick Autodetect).
